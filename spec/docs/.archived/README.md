# Archived Internal Design Documents

この directory は、実装が repository に反映済み、または後続実装で置換済みの内部計画を保持する。

- 現在の要件や未完了作業の入口として扱わない。
- 現行挙動は code、tests、`spec/docs/pub/`、および `spec/docs/` 直下の active documents を優先する。
- 各文書冒頭には、対応実装の commit または後続計画へ置換した理由を記録する。
- この hidden directory は、通常の `rg --files` や既定の LLM file discovery から除外するための配置である。

Archived on 2026-08-15.
